# Analysis From VectorCAST

This is the analysis from the results generated by VectorCAST.

## Boolean Operator

Based on the result for `boolean-operator.c`, VectorCAST does not consider `==` and `|` as logical operators.

## Scope

```c
void bool_exp(bool a, bool b) {
  bool c = a && b; // should MC/DC be measured for each boolean expression?
  if (c) {
    printf("bool_exp decision true\n");
  }
}
```

VectorCAST considers both `a && b` and `c` as boolean expressions (decisions).

## Short Circuit

It seems that VectorCAST considers short circuiting since it said condition `a` is covered.

## Split Condition

In VectorCAST, the split decision is much easier to cover than the original decision.
In other words, VectorCAST does not consider the minor/major conditions in the whole complicated decision.

## Split Nested

VectorCAST is able to consider the nested function invocation in a decision, which is not supported by LLVM-Cov based on its documentation.
